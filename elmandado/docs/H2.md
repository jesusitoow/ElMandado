# Consola H2 (El Mandado)

## Ventana de login

Abrir http://localhost:8080/h2-console y llenar:

| Campo | Valor |
|---|---|
| Saved Settings | Generic H2 (Embedded) |
| Driver Class | `org.h2.Driver` |
| JDBC URL | `jdbc:h2:mem:elmandado` |
| User Name | `sa` |
| Password | (vacío) |

Clic en **Connect**. La JDBC URL debe ser idéntica a `spring.datasource.url`; si no, H2 abre otra base vacía.
